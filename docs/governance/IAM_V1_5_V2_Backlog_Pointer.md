# IAM Version 1.5 — Version 2 Enhancement Backlog Pointer

| Field | Value |
|-------|--------|
| **Document ID** | IAM-V15-V2-BACKLOG-POINTER |

Authoritative V2 enhancement backlog content is in the IAM Version 1.5 specification package document **IAM-014** (*Version 2 Enhancement Backlog & Product Roadmap*). Filename/numbering vs IAM-000 package map is governed by the Project Owner rule that **document content is authoritative**.

| ID (from IAM-014) | Enhancement | V1.5 disposition |
|-------------------|-------------|------------------|
| V2-001 … V2-008 | See IAM-014 | **Deferred** — do not implement in V1.5 |

Any proposed V1.5 scope addition that matches a V2 item must be rejected or escalated under IAM-015 change control.
