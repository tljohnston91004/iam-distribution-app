## Explanation for every deduction (from 100)

### Executive Usability — 86 (−14)
- Lifecycle jargon chips and Present-before-Approve still create first-time friction (−6)
- Free-text owner ids instead of people directory (−4)
- Dark console chrome / density (−4)

### Customer Confidence — 78 (−22)
- Interim scoring profile still disclosed as non-final (−8)
- COI frequently unavailable / weak “if we wait” (−7)
- Soft viewAs ≠ real security (−4)
- Outcome proof / comparable actuals UI still thin (−3)

### Recommendation Explainability — 84 (−16)
- Trust Pyramid is template-based from existing fields; limited SKU-specific storytelling (−8)
- No explicit pairwise “why this beat the next item” (−5)
- Detail page still exposes JSON-centric power view (−3)

### Recommendation Trust — 80 (−20)
- Same interim / COI limitations as confidence (−10)
- Emergency auto-rules still deferred (SD-2) (−4)
- Aging is advisory only (correct policy) but does not prove discipline by itself (−3)
- Historical outcome learning not yet a strong loop (−3)

### Information Hierarchy — 90 (−10)
- Decisions strip can duplicate Management Review items shown elsewhere (−4)
- Ops intake still available (correct) but role switching can reintroduce chrome (−3)
- Recently Completed / Waiting collapse defaults help; users can re-expand into clutter (−3)

### Weekly Management Meeting Readiness — 88 (−12)
- First meeting still benefits from a facilitator (−5)
- Assign/Accept handshake across two people needs practice (−4)
- Complete / Outcome Validation close-out less meeting-native than Approve (−3)

### Executive Decision Support — 87 (−13)
- OEC is excellent; risk of raising OEC instead of finishing work (−5)
- Waiting queue is clear; promotion UX is still “recalculate/re-present” oriented (−4)
- Defer/Reject governance strong; strategic portfolio analytics light (−4)

### Commercial Demonstration Readiness — 72 (−28)
- Not self-serve / PLG polished (−8)
- Visual system not “premium SaaS” (−7)
- Security/RBAC story incomplete (Phase 6) (−7)
- Interim scoring messaging uncomfortable in sales (−6)

### Customer Pilot Readiness — 88 (−12)
- Limited pilot: strong; broad multi-site unattended pilot: not yet (−6)
- Data quality / Keystroke discipline still external dependency (−4)
- Accessibility only baseline (−2)
