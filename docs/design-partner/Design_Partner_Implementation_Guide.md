## 1. Roles

| Role | Responsibilities |
|------|------------------|
| **Project Owner (Decision Priority)** | Approves partners; owns commercial gate; accepts exceptions |
| **Partner Executive Sponsor** | Attends weekly reviews; decides Active Priorities; approves OEC changes |
| **Partner Operations Lead** | Data intake; Calculate · Score · Present; data gap remediation |
| **Partner Owners** | Accept assignments; update progress/blockers |
| **DP Facilitator (CS/Product)** | Runs cadence; fills weekly/monthly templates; captures feedback |
| **Technical Support** | Intake/adapter issues; severity triage |

## 2. Engagement checklist

### Discovery (−2 to 0)
- [ ] Fit score against selection criteria  
- [ ] Classify profile: **Primary ($10M–$50M)** / **Strategic Validation ($50M–$75M)** / **Special (>~$75M, PO-approved only)**  
- [ ] Confirm revenue band does not alone drive accept/reject; check SKU, data, exec, scope  
- [ ] If Strategic Validation: document collaborative-validation (not mature enterprise) expectations  
- [ ] Sample data week assessed (can produce Recommendations?)  
- [ ] NDA / pilot agreement / testimonial clause soft-commit  
- [ ] Success criteria & KPI targets negotiated  
- [ ] OEC initial proposal (default 2 unless justified)  

### Kickoff (Week 0)
- [ ] Executive Kickoff Package delivered  
- [ ] Roles named; meeting calendar set (same day/time weekly)  
- [ ] Owner id/name roster for Assign forms  
- [ ] ViewAs coaching: Executive vs Operations vs Owner (disclose soft viewAs)  
- [ ] First-five-minutes onboarding walked once  

### Configuration (Week 0–1)
- [ ] Company OEC + aging days set and audited  
- [ ] Evidence path confirmed (Keystroke / agreed source)  
- [ ] Baseline Pack completed (see KPI Guide)  

### Weekly operating rhythm (Weeks 2–11)
1. Ops: refresh evidence → Calculate · Score · Present (before meeting)  
2. Exec meeting (≤30 min steady-state): Summary → Momentum → OEC → Decisions → Active Priorities → WIP skim  
3. Assign / Accept within 24–48 hours  
4. Facilitator: Weekly Executive Review Template + feedback taxonomy  
5. Log defects vs feature requests separately  

### Midpoint (Week 6)
- [ ] KPI Progress Report  
- [ ] Executive Feedback Questionnaire  
- [ ] RQI sample  
- [ ] Adjust OEC/process only with documented reason  
- [ ] Go / Adjust / Pause decision  

### Close (Week 12)
- [ ] Final Design Partner Assessment  
- [ ] **Final Executive Review Interview** (required interview template)  
- [ ] ROI Report  
- [ ] Testimonial / Success Story ask  
- [ ] Lessons Learned contribution  
- [ ] Release-stage gate evidence filed (toward Limited Commercial Release when ready)  

---

## 3. Facilitation standards

- **Do not** change scoring formulas or lifecycle rules during pilot without PO approval.  
- **Do** coach Present → Approve sequence explicitly in weeks 1–3.  
- **Do** keep Waiting/Deferred collapsed unless capacity discussion needs them.  
- **Do not** raise OEC to “clear the Waiting queue” without finishing WIP.  
- **Do** record every Sev-1/2 with repro steps.  
- Capture **success moments** the same week they happen (quotes, SKUs, $).  

---

## 4. Escalation

| Severity | Example | Response |
|----------|---------|----------|
| Sev-1 | Board unusable; calculate broken; data loss | Same day; stop meeting claims until fixed |
| Sev-2 | Wrong lane assignment; OEC miscount; Trust Pyramid empty after score | ≤2 business days |
| Sev-3 | Label wording; nice-to-have UX | Backlog for Product Improvement Report |

---

## 5. Exit / early termination

Partner may exit if: data cannot support 3 consecutive weeks; sponsor disengages (&lt;50% attendance over 4 weeks); or mutual no-fit.  
Document reason in Lessons Learned; do **not** count as successful Design Partner for the Limited Commercial Release gate.
