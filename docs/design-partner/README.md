## Purpose

This package is the official **Decision Priority Design Partner Validation Standard — Final Version 1.0 (DPVS v1.0)**.

**IAM Version 1.5** is the **first module implementation** of this company standard. Future Decision Priority modules inherit this framework and adapt only module-specific sections.

---

## Approved partner structure (Final v1.0)

| Profile | Annual revenue | Notes |
|---------|----------------|-------|
| **Primary Design Partner** | ~$10M–$50M | Preferred; aligns with primary commercial market (≤~$50M) |
| **Strategic Validation Partner** | ~$50M–$75M | Optional scalability validation; not a market repositioning |
| **Special strategic engagement** | Above ~$75M | Requires separate Project Owner approval |

| Constraint | Rule |
|------------|------|
| Preferred count | **Two** Primary Design Partners |
| Strategic Validation | **At most one** |
| Maximum (IAM V1.5) | **Three** Design Partners total |

## Approved release stages (Final v1.0)

1. **Internal Validation**  
2. **Design Partner Validation**  
3. **Limited Commercial Release** — may be authorized by the Design Partner Validation gate  
4. **General Commercial Availability** — **separate** future Project Owner decision
