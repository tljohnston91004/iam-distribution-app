## 1. How to use this guide

1. At kickoff, select **3–6 KPIs** (must include ≥1 financial/cash/inventory and ≥1 management productivity).  
2. Lock **Baseline** in Week 1 (date, source system, cohort definition).  
3. Record **Target** and **Success Threshold** (may differ).  
4. Measure at agreed frequency; never change cohort definition mid-pilot without a version note.  
5. Prefer **intervened cohort** (SKUs/Recommendations touched by IAM) over whole-company noise when attribution is unclear.

## 2. KPI dictionary

### 2.1 Inventory investment

| Field | Guidance |
|-------|----------|
| **Definition** | $ on-hand (or available) inventory for defined cohort |
| **Baseline** | Snapshot date T0; export from ERP/Keystroke |
| **Target improvement** | −2% to −5% on trapped-cash / slow-moving cohort (negotiate) |
| **Measurement method** | Same extract definition each cycle; note QOH basis (Available vs On-Hand) |
| **Reporting frequency** | Bi-weekly |
| **Success threshold** | Cohort $ down ≥ negotiated % **or** absolute $ released ≥ floor |

### 2.2 Inventory turns

| Field | Guidance |
|-------|----------|
| **Definition** | COGS / average inventory (cohort or company) |
| **Baseline** | Trailing period agreed at kickoff |
| **Target** | +5% relative on focus set |
| **Method** | Finance + inventory averages; align fiscal calendar |
| **Frequency** | Monthly |
| **Success** | Turns improved vs baseline for focus set |

### 2.3 Gross profit

| Field | Guidance |
|-------|----------|
| **Definition** | GP$ and/or GP% |
| **Baseline** | Prior 3-month average |
| **Target** | Maintain or +0.2–0.5 pts if fill improves |
| **Method** | P&L; annotate promotions/seasonality |
| **Frequency** | Monthly |
| **Success** | No material GP harm attributable to IAM actions; preferably improved |

### 2.4 Cash flow

| Field | Guidance |
|-------|----------|
| **Definition** | Operating cash impact from inventory actions + estimated cash released on completed Recs |
| **Baseline** | T0 cash narrative + IAM estimated cash on Active Priorities |
| **Target** | Documented release ≥ $X (partner-specific) |
| **Method** | Sum completed Recommendation cash estimates where actuals unavailable; replace with actuals when known; label confidence |
| **Frequency** | Monthly |
| **Success** | ≥ $X documented with assumptions |

### 2.5 Slow-moving inventory

| Field | Guidance |
|-------|----------|
| **Definition** | $ / units above weeks-of-supply threshold (e.g. &gt;26 or &gt;40 weeks) |
| **Baseline** | T0 slow-moving report |
| **Target** | −10% $ in acted cohort |
| **Method** | Same WOS rule each time |
| **Frequency** | Bi-weekly |
| **Success** | ≥5% reduction in acted cohort |

### 2.6 Stockouts

| Field | Guidance |
|-------|----------|
| **Definition** | Stockout events or zero-available days on monitored SKUs |
| **Baseline** | Prior 4–8 weeks count |
| **Target** | −10% |
| **Method** | WMS/ERP stockout log or order short ships |
| **Frequency** | Weekly |
| **Success** | Improved vs baseline |

### 2.7 Purchasing efficiency

| Field | Guidance |
|-------|----------|
| **Definition** | Expedite POs, emergency transfers, or buyer rework hours |
| **Baseline** | Prior month count/hours |
| **Target** | −15% expedites |
| **Method** | Purchasing log |
| **Frequency** | Monthly |
| **Success** | Reduced expedites or hours |

### 2.8 Fill rate

| Field | Guidance |
|-------|----------|
| **Definition** | % order lines fully filled |
| **Baseline** | Prior 4–8 weeks |
| **Target** | +1–2 points |
| **Method** | Order management metrics |
| **Frequency** | Weekly or monthly |
| **Success** | Improved or maintained ≥ agreed high bar |

### 2.9 Management productivity

| Field | Guidance |
|-------|----------|
| **Definition** | Minutes in weekly inventory decision meeting + estimated weekly firefight time |
| **Baseline** | Time study / sponsor estimate Week 0 |
| **Target** | Meeting ≤30 min; firefight −25% |
| **Method** | Clock meeting; monthly survey item |
| **Frequency** | Weekly (meeting); monthly (firefight) |
| **Success** | Steady-state meeting ≤30 min weeks 5–12 |
